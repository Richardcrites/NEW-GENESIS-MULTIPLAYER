### A note on the CommonLibSF exception

CommonLibSF is GPL-3.0 with a modding exception. That exception exists so a mod
may link against the game and against modding libraries whose licenses would
otherwise be incompatible. It does **not** exempt a work that links CommonLibSF
from the GPL itself.

PULSAR links CommonLibSF, so PULSAR is a covered work and its source must be
available when binaries are distributed. GPL-3.0 is therefore the honest license
for this project rather than an inconvenience. Publishing this repository is what
brings the previously distributed binaries into compliance.

## Verifying this list

Licenses change between versions. Before redistributing binaries, confirm the
current terms of each dependency at the versions pinned in `vcpkg.json` and the
`.csproj` files rather than trusting this table.
